CODE & REPRODUCIBILITY

Code and reproducibility

This page documents the RIVER analysis software, preprocessing, result generation, and web-data build.

The repository, release version, and runnable commands will be linked here for the public release.

Analysis workflow

  • Structural feature localization: identify duplex-associated features in interaction maps.
  • Fusion scoring: combine multi-resolution interaction support with thermodynamic pairing priors.
  • Representative assembly: select non-conflicting, high-confidence stems.
  • Organization analysis: identify well-folded and mutually exclusive alternative organizations.

Release contents

  • GitHub repository, release tag, environment file, and parameter table.
  • Reproducible notebooks or command-line examples.
  • Input and output schemas with versioned checksums.
  • Catalog files generated from source data rather than edited by hand.

Automated checks

Before release, checks should validate CT/DBN lengths, symmetric pairs, coordinate bounds, duplicate IDs, and VARNA SVG generation.
