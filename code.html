Analysis workflow

  1. Structural feature localization. A modified Canny edge detector finds the anti-diagonal signals that duplexes produce in the interaction map, across multiple resolutions.
  2. Fusion scoring. Each candidate base pair inside a feature is scored by combining interaction support with its thermodynamic pairing probability.
  3. Structure assembly. High-scoring, non-conflicting stems are fixed as constraints; the remaining regions are completed by minimum-free-energy folding.
  4. Structure evaluation. Interaction support, pairing ambiguity and evolutionary conservation are used to identify well-folded structures and mutually exclusive alternatives.

See the method overview on the home page for how each step works.

From raw data to the atlas

Processed interaction data were obtained from CODE. Interaction maps were built with RIC2Structure and normalized with Juicer tools (KR balancing or observed/expected). RIVER then inferred the structures and computed their attributes, producing the files offered here. The dataset list is on the Data & citation page.
