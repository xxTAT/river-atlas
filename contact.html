Help improve the structure catalog

We welcome feedback on data, structure interpretation, web experience, and reproducibility.

Before publication, confirm whether the corresponding author's email can be shown. GitHub Issues is the default public feedback channel.

Feedback channels

  • Data or structure issues: GitHub Issues → Data correction
  • Code and reproducibility: GitHub Issues → Reproducibility
  • Collaboration: project maintainer email or laboratory homepage

Suggested report template

Please include the structure ID, data version, a description, relevant files or screenshots, and a suggested correction so each revision can be recorded in the release changelog.
