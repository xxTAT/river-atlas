How to cite

Please cite the RIVER paper, the original RNA–RNA interaction datasets, the CODE resource, and the structure-rendering software. The release will include CITATION.cff, BibTeX, and a DOI.

Data files

  • Structure catalogs: data/structures/catalog/*.json
  • Secondary structures: CT, DBN, BPSEQ
  • Graphics: VARNA SVG / PNG
  • Heatmap catalogs: data/heatmaps/catalog.json and each dataset's manifest.json
